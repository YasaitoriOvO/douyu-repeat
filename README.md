# 烂梗复读器

这是一个复读烂梗脚本。

[![Greasy Fork Version](https://img.shields.io/greasyfork/v/602295)](https://greasyfork.org/zh-CN/scripts/602295-%E7%83%82%E6%A2%97%E5%A4%8D%E8%AF%BB%E5%99%A8)


## 安装使用

1. 安装并启用 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 进入 [Greasy Fork](https://greasyfork.org/zh-CN/scripts/602295-%E7%83%82%E6%A2%97%E5%A4%8D%E8%AF%BB%E5%99%A8) 安装本脚本使用
3. 打开或刷新斗鱼电脑版直播间，先登录，确认你能手动发送弹幕。
4. 右下角出现“烂梗复读器”面板后，点击“开始”，达到阈值会自动发送。
5. 如果只想观察命中内容，可以手动开启“仅预览”。切换模式会重新统计。

## 设置

### 基础设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 自动开始 | 关闭 | 开启后，打开或刷新直播间会自动开始统计，按保存的“仅预览”状态运行。 |
| 全屏隐藏 | 开启 | 播放器全屏时隐藏面板和猪猪按钮，退出全屏后恢复；统计和复读继续运行。 |
| 仅预览 | 关闭 | 开启后只记录命中的弹幕，不实际发送；关闭后达到条件会自动发送。 |
| 统计窗口（秒） | 30 | 统计最近多少秒内的重复弹幕，范围为 5–300 秒。 |
| 不同观众阈值 | 5 | 同一句弹幕至少由多少个不同昵称发送才触发，范围为 2–100。同一昵称重复发送只算一人。 |
| 发送间隔（秒） | 30 | 两次发送尝试之间的最短间隔，范围为 10–3600 秒。 |
| 同句冷却（秒） | 300 | 同一句弹幕触发后，多久才能再次参与复读，范围为 60–86400 秒。 |
| 最大字数 | 30 | 允许复读的最大长度，范围为 1–100；追加句末词后的总长度也受限制，超出则跳过。 |
| 句末词 | 空 | 直接追加在弹幕末尾，不自动加空格。例如填写“喵”，原弹幕“好耶”会发送为“好耶喵”。 |

“自动开始”“全屏隐藏”“仅预览”切换后立即保存。数字参数、句末词和下方文本设置修改后，需要点击 **保存设置**。

保存设置或切换预览模式会重新统计新增弹幕，并保留当前页面的发送冷却。预览命中也会进入冷却。刷新页面会清空统计和冷却，但保留已保存的设置。

### 过滤设置

展开 **过滤与页面识别**，顶部滑块可切换黑名单和白名单模式。切换模式立即保存并重新统计，名单内容修改后需点击 **保存设置**。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 过滤模式 | 黑名单 | 黑名单模式排除包含指定关键词的弹幕；白名单模式只接受包含指定关键词的弹幕。两种名单不同时生效。 |
| 白名单关键词 | 空 | 多个关键词用英文逗号、中文逗号或换行分隔。白名单模式下，名单为空时不会复读任何弹幕。 |
| 黑名单关键词 | 空 | 多个关键词用英文逗号或中文逗号分隔。黑名单模式下，名单为空时不过滤弹幕内容。 |
| 我的昵称（排除自己） | 空 | 填写自己的斗鱼昵称，排除该昵称发送的弹幕。留空则不按昵称排除。 |

关键词采用 **包含匹配**，不区分英文字母大小写，并统一全半角字符。例如白名单填写 `好耶,精彩`，则“好耶！”和“这波真精彩”均可参与统计。这里过滤的是原弹幕，句末词在发送时追加；人数阈值、字数限制和冷却规则仍然生效。

### 页面识别

通常保持默认即可。斗鱼页面结构变化、其他脚本修改了页面时，可以调整 CSS 选择器。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 弹幕列表 CSS | `.Barrage-list` | 定位右侧弹幕列表。 |
| 单条弹幕 CSS | `.Barrage-listItem` | 定位列表中的每条弹幕。 |
| 弹幕内容 CSS | `.Barrage-content` | 提取单条弹幕的文字。 |
| 观众昵称 CSS | `.Barrage-nickName` | 提取昵称，用于人数去重和排除自己。 |
| 输入框 CSS | `.ChatSend-txt` | 定位弹幕输入框，支持普通输入框和富文本编辑器。 |
| 发送按钮 CSS | `.ChatSend-button` | 定位网页上的发送按钮。 |

面板会分别显示输入框和发送按钮的识别结果。若显示“未识别”：

1. 点击 **点选输入框**，再点击网页上的弹幕输入区域。
2. 点击 **点选发送按钮**，再点击网页上的发送按钮。
3. 点选结果自动保存，确认识别正常后点击 **开始**。

点选过程中会暂停复读，并拦截用于选择控件的点击；按 `Esc` 可取消。页面结构改变后可能需要重新点选。
